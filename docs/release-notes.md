**Chargewire ODBC Driver 2.3.2**, built on Chargewire C++ 2.3.0.

- Reuse HTTP connections and read Arrow streams more efficiently.
- Preserve the ODBC API, connection defaults and compatibility with Hardcharger 2.7.0.

The release gates run the unit and live suites on all four platforms against released Hardcharger 2.7.0, over HTTP and verified TLS. Windows DLL and MSI are EV-signed and verified before publication.
